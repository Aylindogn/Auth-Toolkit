# 🛡️ 420 Auth Toolkit: Secure Identity & Access Management

This project is a comprehensive cybersecurity toolkit focused on robust authentication and authorization mechanisms, developed as part of the **BIL 420 (Computer Engineering Capstone)** curriculum.

## 🚀 Project Overview
The `420 Auth Toolkit` is designed to provide a secure foundation for identity management by addressing modern security challenges through industry-standard protocols and Secure Software Development Lifecycle (SDLC) principles.

## ✨ Key Features
* **Multi-Factor Authentication (MFA):** Implementation of layered security to prevent unauthorized access.
* **Vulnerability Management:** Tools for identifying and mitigating common authentication flaws such as brute-force attacks.
* **Secure Session Handling:** Advanced management of encrypted session tokens and process-level security.
* **Threat Modeling:** An integrated framework to assess and defend against identity-based attack vectors.

## 💻 Technical Stack & Implementation
* **Language:** C (Systems Programming)
* **Concurrency:** POSIX Threads (`pthreads`) for handling simultaneous authentication requests.
* **Inter-process Communication:** Secure use of pipes and shared memory for sensitive data handling.
* **Environment:** Developed and tested on Windows 11 using MSYS2/GCC.
